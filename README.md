# GitHub Insights

**GitHub Insights** é uma aplicação web em desenvolvimento que tem como objetivo analisar perfis do GitHub e transformar dados públicos em informações úteis para desenvolvedores.

O projeto busca ajudar desenvolvedores a compreender melhor seus perfis, organizar seus portfólios e identificar oportunidades de melhoria, com potencial para auxiliar também na avaliação técnica de perfis por recrutadores.

## Funcionalidades atuais

- Busca de perfis públicos do GitHub por nome de usuário.
- Exibição dos dados do perfil encontrado.
- Tratamento de erros da API do GitHub.
- Interface com estados de carregamento e mensagens de erro.

## Tecnologias utilizadas

- JavaScript
- React
- Vite
- HTML5
- CSS3
- Git e GitHub

## Como executar o projeto

### Pré-requisitos

- Node.js
- npm

### Instalação

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd github-insights
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o ambiente de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Abra no navegador o endereço local informado pelo Vite.

## Scripts disponíveis
